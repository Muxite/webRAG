## 1. What changed since mint03 (host-invisible unless stated)
- `host_prefetch` (5th `LEDGER_HOST_MODULES` token): at the host's single exit, before `host_derive`, the host resolves
  every slot entity of the mandate to its Wikipedia page (Wikipedia search API, verified against the fetched infobox; general
  search connector only as fallback), fetches it through `connector_http` (never `AgentIO.visit`, so `output.pages`, visit
  counts and validator grounding are untouched), and registers the FULL text plus structured infobox entries with
  `source="host_prefetch"`. Budget is structural: one resolve + one fetch per slot entity. No caps.
- quantity_index: flattened superscripts (`km\n2`) index as `km2`; split parenthetical restatements captured; currency-prefixed
  values indexed; uncapped index for host pages.
- ledger_tools: operands selected under a shared unit across entities (no conversion; narrows, never widens).
- Search factory fails closed on an unknown provider. Fixtures: `IDEA_TEST_FIXTURES=replay` (declared; see §5).
