Per-cell flag (report section `backed_only_flag`): every non-trivial answer number is
verbatim-backed (ambiguity ≤ 1) and none has a derivation explanation — the "copied
instead of computing" signature. mint01 development evidence: 7/7 flagged cells wrong.

- Metric: flag precision = wrong-rate (score < 0.5) among flagged cells, pooled over all
  usable mint02 cells; dev/holdout and per-model reported alongside.
- Decision rule: flag precision ≥ 90% AND n_flagged ≥ 8 → PROMOTE as a deterministic
  wrongness flag. n_flagged < 8 → verdict "insufficient n" (named as such, not spun).
  Precision < 90% at n ≥ 8 → REJECT; stays informational.
